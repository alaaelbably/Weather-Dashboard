# Weather-Dashboard
A responsive Weather Dashboard Web App that shows real-time weather, air quality, sunrise/sunset, and hourly forecasts. It supports geolocation, city search, Celsius/Fahrenheit toggle, and dark/light themes — all powered by the OpenWeatherMap API.

Features
Detects your location automatically
Search any city worldwide
Switch between Celsius (°C) and Fahrenheit (°F)
Sunrise & Sunset times
6-hour forecast with wind & humidity
Air Quality Index (AQI)
Dark/Light theme toggle
Mobile-friendly design

Tech Stack
JavaScript (ES6+)
Bootstrap & Icons
OpenWeatherMap API
